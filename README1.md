Auto Ticket Classification Using Flow Designer

An automated workflow built in ServiceNow to streamline the ticket classification process. This project automatically categorizes incoming tickets based on predefined conditions, reduces manual effort, and improves ticket routing and processing.

🚀 Features

* Service Catalog / Ticket Submission: User-friendly form for creating and submitting support tickets.
* Flow Designer Workflow: Automated flow for analyzing and classifying incoming tickets.
* Automatic Categorization: Tickets are classified based on conditions such as category, priority, or issue type.
* Dynamic Routing: Automatically assigns tickets to the appropriate group based on the classification.
* Business Rules and Validations: JavaScript-based logic can be used for additional validations and processing.

📂 Project Structure

* "docs/": Technical documentation and workflow diagrams.
* "flow-designer/": Step-by-step breakdown of the ticket classification flow.
* "scripts/": Client-side and server-side JavaScript code.
* "screenshots/": Visual previews of the ServiceNow instance setup.

🛠️ Setup Instructions

1. Import the Update Set or Studio Application (if applicable).
2. Configure the required ticket categories and assignment groups.
3. Create and configure the Flow Designer workflow "Auto Ticket Classification Flow".
4. Define conditions for automatically classifying incoming tickets.
5. Configure actions to assign tickets to the appropriate support group.
6. Activate the Flow Designer workflow and test it with sample tickets.
